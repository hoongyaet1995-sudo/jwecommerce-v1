## Implementation

- Overview and operation completion expose `StockConfirmationSnapshot`: one task's balance/version, exact listing/model/shop/location, status, quantity, current error, request ID and check metadata. Shared cards consume this projection instead of combining the overview flag with independently fetched latest-100 history. Confirmed zero is retained; stale/unknown observations are not turned into zero or summed across warehouses. History remains audit data.
- `TaskStockReadback` is the common automatic/manual observation engine. The new operation/task confirmation POST requires an admin with `inventory.edit` or super-admin permission, validates the immutable request tuple, rejects ownership/version/mapping/shop/facility changes, takes the existing store readback lock and rechecks identity after the provider call. Same-key replay uses the existing attempt audit; another manual check is subject to a 15-second cooldown and route throttling. Manual checks never publish, resume waiting transfers, enqueue a push or change the JW ledger. Automatic checks keep the four-attempt budget and their existing transfer continuation.
- Shopee/Lazada publishers preserve accepted-write request ID/time, exact destination/shop and observed quantity/check time on successful or uncertain post-write readback. Uncertain exceptions allowlist diagnostics; readback audit stores only inventory fields. Exact confirmation removes the current code/message and retains previous worker attempts. No new schema/storage subsystem was introduced.
- Cards show `Confirming stock`, `Sync failed` or `Confirmation needs review`, with last checked time/count and an explicit `Check confirmation` when eligible. Overview polling refreshes pending confirmations and discards older responses. First Count completion uses the same projected status. The chevron expands only through activation, with native Enter/Space, visible focus and `aria-expanded`; internal checks neither fold the card nor issue duplicate requests. Existing theme, image assets, one Shared total and Independent entry points are retained.
