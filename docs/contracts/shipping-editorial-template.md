# Shipping editorial template

Shipping & Delivery — Editorial is a draft starter in Store Policies. Six sections use the common page container and Content / Design / Advanced Inspector. New delivery_table owns source, column labels, manual destinations and note. Service Highlights, Story with Steps, Minimal FAQ and Help Panel are optional shared presets; existing defaults remain unchanged.

Shipping Settings mode projects enabled configured rates at render time. Estimated days are copied only when configured; otherwise Confirm at checkout. Fees always read Calculated at checkout, because eligibility and pricing remain checkout responsibilities. Manual copy never modifies checkout settings. Builder unavailable states distinguish a failed/unavailable settings load from an empty configured list.

Hero supports introduction and a secondary action. Primary delivery action anchors to the generated table section. Track your order uses the existing verification route. Contact us opens the existing support widget. Managed images are registered idempotently by ShippingEditorialMediaSeeder.

All settings are English. Shared typography, images, stable item identities, borders, container inheritance and click-to-focus remain in force. Weekend/holiday policy copy must be edited before publishing. This template does not publish itself or change the homepage.
