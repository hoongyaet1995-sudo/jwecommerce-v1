# Xenibox Email Editor

This editor is adapted from the official EmailBuilder.js Vite/MUI example.

- Upstream: https://github.com/usewaypoint/email-builder-js
- Upstream revision: `ce3e610`
- License: MIT (see `LICENSE`)
- Runtime: compiled static files in `crm/assets/email-builder`

Build with `npm install` followed by `npm run build`. Node.js is required only when rebuilding the editor; deployed CRM installations only need the compiled assets.
