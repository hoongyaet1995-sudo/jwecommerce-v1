# Wedding PLP v1 visual contract

Sample only; no theme activation or live template changes. Approved direction: modern editorial, ivory/olive, Cormorant Garamond + Inter, 3 desktop columns, no header/footer in sample. Hero media full bleed; copy and catalog use canonical Page Width frame in Standard/Wide/Full.

- Collection heading/description: actual Category/Collection fields.
- Hero: existing category/collection banner/media ownership; gradient is CSS, text editable HTML.
- Cards: actual product/service title, subtitle and media; View collection opens PDP. No Add to cart or Quick Buy for quote products. Price on request follows configured price visibility, never globally hardcoded for direct-purchase products.
- Count/sort/filter: shared catalog GET contracts. Any category tabs shown in concept require actual category destinations preserving scope; omit if unsupported/redundant. Not invented service filters.
- Category labels and cards are sample content, not live catalog creation.
- Lower enquiry invitation must lead to an actual editable contact/CMS destination; do not invent a general enquiry endpoint or silently submit a productless quote.
- Motion and hover behavior require real renderer verification; raster proves composition only.
