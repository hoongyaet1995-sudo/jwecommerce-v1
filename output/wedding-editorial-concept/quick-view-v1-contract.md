# Wedding Quick View concept v1

Visual sample only. Shared quick-buy/preview machinery is the intended integration owner; no separate service product model. Current task does not implement availability of quote-mode preview triggers.

Media/title/category/summary/description/price visibility from selected Product and Product Media. Thumb selection existing shared image identity. No configured variants shown in sample; integration must preserve selectable actual variants and pass selected variant to existing enquiry. Request a quote opens existing enquiry workflow with appropriate modal focus restoration; never nests dialogs without explicit focus management. View full collection goes actual PDP. No quantity/cart/stock/booking UI for quote mode. Direct-buy products must preserve existing normal behavior. All conditional labels and helper text are system copy, not invented per-product claims. Desktop and mobile acceptance required before integration closure.
