# Wedding Editorial Landing Concept v1

Status: visual sample only, no live template registration or application changes.
Approved direction: modern editorial, elegant and expressive; ivory #F7F4EE, olive #465348, pale green #E5E9E1, charcoal #292923. Proposed Cormorant Garamond + Inter subject to font registration audit before integration. No header/footer in sample.

| Region | Existing capability / proposed integration |
|---|---|
| Hero | hero_banner or hero_slider editorial-overlay: editable images/copy/actions, canonical content gutter |
| Brand / photographer / featured story | media_text_split: editable text, images and destination; story links require actual CMS destinations |
| Photo marquee | GAP: announcement_bar currently renders title text with tickerSpeed and hover CSS; cannot present photo gallery as existing controls. Add reusable gallery layout preset with image Add/Delete/Reorder, crop/alt, speed and pause; confirm direction/manual mobile/reduced motion implementation before promising controls. |
| Services | shop_navigation photographic collection cards, using real catalog destinations and purchase modes |
| Process | existing timeline/story semantic content, editorial layout may need preset |
| Testimonials | editable real client content only; sample quote explicitly fictional, no endorsement claims |
| Closing CTA | editable content/media/action; point to real service/enquiry route, not guessed booking availability |

Motion is proposed behavior, not something a still raster sample proves. Actual layout presets must pass sparse-data Inspector, save/refresh and Builder/public parity acceptance. Photos are original generated concept visuals, never harvested photographer assets.
